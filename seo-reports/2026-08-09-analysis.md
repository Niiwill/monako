# Daily SEO Performance Analysis — 2026-08-09

**Window:** 2026-07-09 → 2026-08-05 (28d) vs prior 28d
**Snapshot:** `gsc-history/2026-08-09.json`

---

## Executive summary

Web clicks are up 119% year-on-period and the site is holding ~2,020
clicks/week with no seasonal decay yet. But the two findings that matter are
both about **measurement, not performance**:

1. **A third of the site's search presence has never been reported.** Image
   search delivers **867 clicks from 42,168 impressions** in this window — up
   from 257/16,035 — and every prior report in this log was web-only. True
   site total is **8,859 clicks**, not 7,992.
2. **Every declining query improved its position while losing 40–53% of its
   CTR.** That is SERP-feature encroachment (image pack, map pack, local
   pack), not a ranking problem — and it is largely the business's *own*
   surfaces taking the clicks.

Site-wide the same signature holds: **position improved 6.12 → 5.41 while web
CTR fell 6.48% → 6.28%.**

## Key insights

- **Image search is the fastest-growing channel and was invisible.** Clicks
  +237%, impressions +163%, average position **21.7 → 13.2**.
  `plaze-herceg-novi.html` alone earns 594 image clicks from 18,396
  impressions at position 7.8.
- **Beach content dominates both channels.** `herceg novi plaze` is position
  1.4 in web (15.0% CTR) *and* position 1.3 in images (2,348 impressions).
- **The decline list is entirely position-1-to-2.5 local queries:**
  `blatna plaza igalo smestaj` CTR 11.7% → 6.5% at **identical position 1.9**;
  `plaza u igalu` 39.2% → 22.2% at improved position 1.2;
  `blatna plaza igalo mapa` 14.6% → 8.0% at position 1.0. These are queries
  where a map or image pack sits above the blue link.
- **The homepage is the only page with a negative click delta** (659 → 654)
  while every other significant page grew — `plaze-herceg-novi` +3,082,
  `atrakcije` +434, `10-razloga` +320, `restorani-hn` +275.
- **Growth is concentrated in one topic.** The top 7 growing queries are all
  beach terms; `plaze herceg novi` went 3.6 → **1.3** with CTR 19.6% → 44.3%.
- **Indexing: one genuine anomaly.** `rent-a-bike-herceg-novi-igalo.html` is
  *Discovered – currently not indexed*. (`en/index.html` reads "unknown" but
  `/en/` is indexed and canonical — that one is harmless.)

## Opportunities — ranked by impact

### 1. Image SEO on the beach cluster — ~42,000 impressions, position 13.2
**Why:** Image search is 33% of the site's impressions and its average
position is 13.2 — far worse than the same queries in web (1.2–1.4). The
content already wins the topic; the *images* are ranked mid-pack. Moving
image position from 13 to top-5 on queries already held in web is the largest
untapped volume on the site.

**Evidence:** `igalo plaze` web position 1.2 with 10.1% CTR against 28%
expected — 393 missed clicks. The gap is not a snippet problem; users on beach
queries switch to the Images tab, where the site sits at 1.9.

**Steps:**
1. Audit `vesti/plaze-herceg-novi.html` images: descriptive filenames
   (`blatna-plaza-igalo-lekovito-blato.webp`, not `img_2.webp` — the repo
   currently has `img_1.webp`, `img_2.webp`), specific `alt` text naming the
   beach, and captions.
2. Add `ImageObject` entries to the existing JSON-LD with `contentUrl`,
   `caption` and `license`.
3. Ensure every beach section has at least one image with `width`/`height`
   and `loading="lazy"` except the LCP image.
4. Add an image sitemap block for the beach pages.

### 2. `igalo` — 14,380 impressions, position 6.7, 1.4% CTR
**Why:** the single biggest query on the site, missing ~379 clicks against
expected CTR for its position. Deploy #5's title test on `10-razloga` reaches
its 14-day verdict now.

**Steps:**
1. Read the deploy-#5 verdict today (baseline 1.5% @ 6.8).
2. If CTR has not recovered to ≥1.7%, revert to the PR #56 variant
   (`Igalo, Crna Gora – 10 Razloga za Odmor: Plaže i Blato 2026`) — the only
   version never contaminated by same-day edits.
3. Do not touch anything else on that page until the revert has 14 days.

### 3. `herceg novi` — 1,756 impressions, position 13.2
**Why:** PR #76's hub expansion (orientation, how-to-get-there, weather) has
moved it 15.1 → 13.2 and it is still climbing. Positions 11–13 are one step
from page 1, where CTR roughly triples.

**Steps:**
1. Hold — the hub content merged Jul 30 and needs its full window.
2. Add the homepage → `atrakcije` internal link deferred on Aug 1 (the
   deploy-#3 freeze has now expired).
3. Re-check position on Aug 13.

### 4. `rent-a-bike-herceg-novi-igalo.html` — not indexed
**Why:** the page has existed since Jul 13 and Google has discovered but never
crawled it. It cannot rank at all. Its Serbian twin is indexed and its query
space is small, so impact is modest — but the fix is two minutes.

**Steps:**
1. URL Inspection → Request Indexing.
2. If still uncrawled in 7 days, add an internal link from
   `iznajmljivanje-bicikla-herceg-novi-igalo.html` (currently the only
   inbound path is the sitemap and the homepage news block).

3. Re-check whether Google swaps the ranking URL within 14 days.

## Method note

Three consecutive reports have now found that a headline number meant
something other than it appeared to: the funnel finding (an `<aside>` filter),
the commercial-decline finding (organic-only measurement), and today's
CTR-erosion finding (web-only measurement). In all three cases the raw metric
pointed one way and decomposition pointed the other. **The site is not losing
CTR — it is being served across more surfaces than the reporting covered.**
